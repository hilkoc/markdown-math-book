# Four Curves, One Field

## The Problem

> **Problem 5.** The parabola $y=x^2$, the circle $x^2+y^2=1$, the node $y^2=x^2(x+1)$ and the cusp $y^2=x^3$ are pairwise non-isomorphic. Yet each of them can be parametrized by rational functions of a single variable. What do these four curves have in common? Find an object, attached to every curve, that is the same for all four. Then say exactly what that object remembers about a curve, and what it forgets.

The first sentence collects results from Part I. Over $\mathbb{C}$ the parabola is a line (Chapter 2). The circle is the hyperbola, which is the line with one point removed, and its units show that it is not a line (Chapter 2). The node and the cusp are singular, so they are isomorphic to neither of these (Chapter 4), and Theorem 4.8 showed that they are not isomorphic to each other.

The second sentence collects the parametrizations of Chapter 1.

| Curve | Parametrization | Parameter recovered as |
|---|---|---|
| parabola | $(t,\,t^2)$ | $t=x$ |
| circle | $\bigl(\frac{1-t^2}{1+t^2},\,\frac{2t}{1+t^2}\bigr)$ | $t=\frac{y}{x+1}$ |
| node | $\bigl(t^2-1,\,t(t^2-1)\bigr)$ | $t=\frac yx$ |
| cusp | $(t^2,\,t^3)$ | $t=\frac yx$ |

In three of the four cases the parameter is a quotient of polynomial functions, not a polynomial function itself, and Chapter 2 showed that on the cusp it cannot be one. So the common feature should live among quotients: among rational functions.

Lurking behind the problem is the cubic $E:\ y^2=x^3-x$. Is it a fifth member of the family? By the end of the chapter we will be able to ask that question precisely, though not yet to answer it.

## First Attempts

**Remove the bad points.** Each parametrization becomes a bijection once a few points are removed.

- The parabola: $\mathbb{A}^1\to$ parabola, with no exceptions.
- The circle: $\mathbb{A}^1$ minus $\{\pm i\}$ $\to$ the circle minus $P_0=(-1,0)$.
- The node: $\mathbb{A}^1$ minus $\{\pm1\}$ $\to$ the node minus the origin.
- The cusp: $\mathbb{A}^1$ minus $\{0\}$ $\to$ the cusp minus the origin.

These restricted maps are isomorphisms. On the cusp minus the origin, for instance, $x$ is never zero, so $1/x$ is a polynomial function there and so is $t=y/x$. The same trick works for the node, and for the circle with $1/(x+1)$. So each of the four curves contains a copy of the line with finitely many points removed. Any two of them contain isomorphic pieces, for instance copies of the line minus the five points $0,\pm1,\pm i$.

That is a real answer, but an awkward one. It needs explicit maps, and removing points is something we do to the curves, not an invariant computed from them. We want an object attached to each curve that does not notice finitely many points at all.

**Rational functions don't notice points.** A quotient of polynomial functions, such as $y/x$ on the cusp, is defined everywhere except where its denominator vanishes. Its failure at the origin becomes invisible if we simply treat it as an element of the field of fractions of $k[C]$. In that field $t=y/x$ satisfies $t^2=y^2/x^2=x$ and $t^3=y$, so the whole field is generated by $t$. The same happens for the circle, with $t=y/(x+1)$, and for the node.

**A warning.** Not every parametrization lets us recover the parameter. The map $t\mapsto(t^2,t^4)$ parametrizes the parabola too, but it sends $t$ and $-t$ to the same point, so $t$ is not a rational function of $x=t^2$ and $y=t^4$. A parametrization therefore does not automatically identify the curve's field with the field of rational functions in $t$. We will need a theorem, due to Lüroth, which says that a better parametrization can always be found.

**And $E$?** Try the same on $E:\ y^2=x^3-x$. Lines through $(0,0)$ have slope $t=y/x$, and then $t^2=(x^3-x)/x^2=x-1/x$. So $x$ satisfies $x^2-t^2x-1=0$, whose discriminant is $t^4+4$. The field of $E$ is therefore generated by $t$ together with $s=2x-t^2$, where $s^2=t^4+4$. That is the field of rational functions in $t$ with one square root adjoined. Nothing in the computation says whether a cleverer choice of parameter would make the square root unnecessary.

## The Ideas We Need

### The function field {-}

**Definition 5.1.** Let $C$ be an affine curve whose coordinate ring $k[C]$ is a domain. Its **function field** is the field of fractions
$$k(C)=\operatorname{Frac}k[C].$$
Its elements are the **rational functions** on $C$. A rational function $\varphi$ is **defined** (or **regular**) at $p$ if it can be written as $g/h$ with $h(p)\neq0$, that is, if $\varphi$ lies in the local ring $\mathcal O_{C,p}$ of Chapter 4.

Three remarks.

- A rational function is defined at all but finitely many points. If $\varphi=g/h$, it is defined wherever $h\neq0$, and a nonzero polynomial function vanishes at only finitely many points of a curve. For a plane curve $f=0$ this is Bézout's theorem from Chapter 3, or [F, §1.6].
- Every local ring $\mathcal O_{C,p}$ sits inside $k(C)$, and $k(C)$ is the field of fractions of each of them. The function field is what is left of the local rings when we forget which point they belong to.
- For a projective curve, take the function field of any affine chart. The charts' fields agree, because overlapping charts share all but finitely many points and the same rational functions.

**Examples.** The line and the projective line both have function field $k(t)$. The hyperbola has coordinate ring $k[x,y]/(xy-1)=k[x,x^{-1}]$, so its function field is $k(x)$. The parabola has function field $k(x)$ too.

The function field of a curve is finitely generated over $k$ and has transcendence degree 1. For a plane curve $f=0$, $k(C)=k(x,y)$, where $x$ is transcendental over $k$ and $y$ is algebraic over $k(x)$ (provided $f$ involves $y$). Fields like this are called **algebraic function fields of one variable**, and they are the main subject of [S].

> **Look up.** Function fields: [H, I.3, Theorem 3.2(d), and I.4]; [F, §2.4 and §4.2]; [S, §1.1].

### Rational maps {-}

**Definition 5.2.** A **rational map** $\varphi:C\dashrightarrow D$, from a curve $C$ to a curve $D\subset\mathbb{A}^m$, is given by rational functions $\varphi_1,\dots,\varphi_m\in k(C)$ such that, at every point $p$ where all of them are defined, $(\varphi_1(p),\dots,\varphi_m(p))$ lies on $D$. It is **dominant** if it is not constant; for curves, this means its image is infinite. A **birational map** is a dominant rational map with a rational inverse. Curves related by a birational map are **birationally equivalent**.

A dominant rational map pulls rational functions back. If $g\in k(D)$, then $\varphi^*g=g\circ\varphi$ is a rational function on $C$. Dominance guarantees that a denominator never pulls back to the zero function, because a nonzero function on $D$ vanishes at only finitely many points, while $\varphi$ takes infinitely many values. So $\varphi^*:k(D)\to k(C)$ is a homomorphism of fields over $k$, and hence injective.

**Theorem 5.3 (the field dictionary).** The rule $\varphi\mapsto\varphi^*$ is a bijection between dominant rational maps $C\dashrightarrow D$ and $k$-embeddings $k(D)\hookrightarrow k(C)$, and birational maps correspond to isomorphisms. Consequently the following are equivalent:

1. $k(C)\cong k(D)$ as fields over $k$;
2. $C$ and $D$ are birationally equivalent;
3. $C$ and $D$ contain isomorphic open subsets, that is, they become isomorphic once finitely many points are removed from each.

The proof is that of Theorem 2.3, with rational functions in place of polynomial functions. An embedding $h:k(D)\to k(C)$ is determined by the images $h(\bar y_i)$ of the coordinate functions, and those images define the map.

So the function field is a complete invariant for birational equivalence, just as the coordinate ring was for isomorphism. Two more facts complete the picture.

- Every curve is birationally equivalent to a plane curve. By the primitive element theorem, $k(C)=k(x,y)$ for suitable $x$ and $y$, and the polynomial relation between them defines a plane curve with the same function field.
- A curve is **rational** when it is birationally equivalent to the line, that is, when $k(C)\cong k(t)$.

> **Look up.** Rational maps and birational equivalence: [H, I.4, Theorem 4.4, Corollary 4.5 and Proposition 4.9]; [F, Chapter 6 and §7.1].

### Parametrizations are field embeddings {-}

A rational parametrization $(x(t),y(t))$ of a plane curve $C$ (Definition 1.2) is exactly a dominant rational map $\mathbb{A}^1\dashrightarrow C$. By the field dictionary it corresponds to the embedding
$$k(C)\hookrightarrow k(t),\qquad x\mapsto x(t),\quad y\mapsto y(t),$$
whose image is the subfield $k\bigl(x(t),y(t)\bigr)$. The parametrization is birational exactly when this image is all of $k(t)$, that is, when $t$ can be written as a rational function of $x(t)$ and $y(t)$, as in the table of Section 5.1. For $t\mapsto(t^2,t^4)$ the image is $k(t^2)$, a proper subfield.

To repair parametrizations that are not birational, we need two facts about subfields of $k(t)$. The first measures a single rational function.

**Lemma 5.4.** Let $s=g(t)/h(t)$, with $g$ and $h$ coprime polynomials, not both constant, and let $n=\max(\deg g,\deg h)$. Then $[k(t):k(s)]=n$. Moreover, for all but finitely many values $c$, the equation $s(t)=c$ has exactly $n$ solutions $t$.

*Sketch.* The element $t$ is a root of $g(X)-s\,h(X)$, a polynomial in $X$ of degree $n$ with coefficients in $k(s)$. This polynomial is irreducible over $k(s)$: it is linear in $s$, and $g$ and $h$ are coprime, so Gauss's lemma applies. For the second statement, $g(X)-c\,h(X)$ has $n$ distinct roots for all but finitely many $c$. $\square$

So the degree of the field extension equals the number of values of $t$ lying over a typical value of $s$. That is the degree of $s$ as a map from the projective line to itself, and Chapter 8 develops degrees of maps in general.

**Theorem 5.5 (Lüroth, 1876).** Every field $K$ with $k\subsetneq K\subseteq k(t)$ has the form $K=k(s)$ for some $s\in K$.

*Idea of proof.* Take the minimal polynomial of $t$ over $K$. Its coefficients lie in $K$, and not all of them lie in $k$, since $t$ is transcendental over $k$. Lüroth showed that any coefficient $s$ not in $k$ already generates $K$. A comparison of degrees using Lemma 5.4 shows that $[k(t):k(s)]=[k(t):K]$, so the inclusion $k(s)\subseteq K$ is an equality. $\square$

**Corollary 5.6.** A curve can be parametrized by rational functions if and only if it is rational. Moreover, every parametrization can be replaced by a birational one: if the image of $k(C)$ in $k(t)$ is $k(s)$, reparametrize by $s$.

For $t\mapsto(t^2,t^4)$, the minimal polynomial of $t$ over $k(t^2,t^4)=k(t^2)$ is $X^2-t^2$. Its coefficient $s=t^2$ gives the obvious birational parametrization $(s,s^2)$.

For curves, then, "can be parametrized" and "is birational to the line" are the same. In higher dimensions this is far from automatic. Over $\mathbb{C}$ the analogue of Lüroth's theorem still holds for surfaces, by a theorem of Castelnuovo from 1894. It fails in dimension three: in 1971–72, Clemens and Griffiths, Iskovskikh and Manin, and Artin and Mumford found threefolds that can be parametrized but are not birational to projective space.

> **Look up.** Lüroth's theorem: van der Waerden, *Algebra*, Volume 1, gives an elementary proof along these lines. [H, IV, Example 2.5.5] proves it again with the Hurwitz formula of our Chapter 11.

## The Solution

**Theorem 5.7.** The parabola, the circle, the node and the cusp each have function field isomorphic to $k(t)$. Consequently the four curves are birationally equivalent to the line and to one another, although no two of them are isomorphic.

*Proof.* In each case, let $t$ be the rational function in the last column of the table in Section 5.1. Then $t\in k(C)$, and the parametrization expresses $x$ and $y$ as rational functions of $t$. Hence $k(C)=k(x,y)=k(t)$. Finally, $t$ is transcendental over $k$, because $k(C)$ has transcendence degree 1. $\square$

The birational maps are explicit. For instance, the map from the node to the cusp and its inverse are
$$(x,y)\mapsto\Bigl(\frac{y^2}{x^2},\ \frac{y^3}{x^3}\Bigr),\qquad (x,y)\mapsto\Bigl(\frac{y^2}{x^2}-1,\ \frac{y^3}{x^3}-\frac yx\Bigr).$$
Both preserve the function $t=y/x$, and both are defined away from the origin. Neither extends to an isomorphism, as Chapter 4 proved.

### What the function field remembers {-}

By Theorem 5.3, the function field determines a curve exactly up to birational equivalence. That means up to removing finitely many points, and up to anything that happens at finitely many points. In particular it forgets three kinds of information.

- **Singular points.** The node and the cusp have the same function field as the line.
- **Missing points.** The line, the line minus a point (the hyperbola, or over $\mathbb{C}$ the circle) and the projective line all have function field $k(t)$.
- **The embedding.** The equation, the plane it lives in and its degree are all forgotten: the parabola has degree 2 and the node and cusp have degree 3, yet all have field $k(t)$.

What remains is still a great deal. Chapter 6 shows how to recover points from the field alone, as valuations. Chapter 7 shows that each function field of one variable corresponds to exactly one smooth projective curve, and for the four curves here that curve is the projective line. So here is the answer to the problem. The four curves share their function field $k(t)$. The function field remembers exactly one smooth projective curve, here $\mathbb{P}^1$, and each of the four curves comes from it by removing points and, for the node and the cusp, by pinching it at one point.

### The field remembers arithmetic, too {-}

Over a field that is not algebraically closed, birational equivalence uses rational functions with coefficients in that field, and it can distinguish curves that $\mathbb{C}$ cannot.

Over $\mathbb{Q}$, the circle's function field is $\mathbb{Q}(t)$, by Chapter 1's parametrization. But the conic $x^2+y^2=3$ has no rational points (Proposition 1.5), and that prevents its function field from being $\mathbb{Q}(t)$. A birational map from the line, defined over $\mathbb{Q}$, would send all but finitely many of the infinitely many rational numbers to rational points of the conic. Over $\mathbb{Q}(\sqrt3)$, or over $\mathbb{C}$, the conic's function field does become rational. Chapter 16 shows that this is the only obstruction: a curve of genus 0 is rational over $\mathbb{Q}$ exactly when it has a rational point, as Theorem 1.6 announced.

### The open question {-}

For $E:\ y^2=x^3-x$, Section 5.2 found that $k(E)=k(t,s)$ with $s^2=t^4+4$. By Lüroth's theorem, $E$ can be parametrized exactly when this field equals $k(u)$ for some single element $u$. Chapter 1's question, whether a smooth cubic can be parametrized, has become a question about one field.

We cannot answer it yet, and comparison with similar fields shows why it is subtle. The field $k(t,s)$ with $s^2=t^2+1$ is rational (Variation 2), and so is the one with $s^2=t^3+t^2$. Yet $k(E)=k\bigl(x,\sqrt{x^3-x}\bigr)$ looks no more complicated.

Chapter 9 will find an invariant of function fields, the space of regular differentials, which is zero for $k(t)$ and nonzero for $k(E)$. That will settle the question: $E$ cannot be parametrized.

## What Just Happened

- **Rational functions do not notice finitely many points.** So the field of rational functions is a birational invariant. The dictionary of Chapter 2 has a birational version: dominant rational maps correspond to field embeddings, and birational equivalence, isomorphic function fields and isomorphic open subsets all amount to the same thing.
- **Parametrizations are field embeddings.** A parametrization is an embedding $k(C)\hookrightarrow k(t)$. Lüroth's theorem says that its image is always some $k(s)$, so "can be parametrized" means "is rational".
- **The four curves of the problem all have function field $k(t)$.** They are the projective line with points removed and, for the node and the cusp, with a singularity added. The function field forgets singularities, missing points and embeddings, and remembers the curve up to birational equivalence.
- **Over a field that is not algebraically closed, function fields carry arithmetic.** The circle and the conic $x^2+y^2=3$ have the same field over $\mathbb{C}$, but different fields over $\mathbb{Q}$.
- **The question about $E$ is now a question about a field.** It can be parametrized exactly when $k(E)\cong k(t)$.

## Threads

**What is a curve?** We now have two answers: the coordinate ring, up to isomorphism, and the function field, up to birational equivalence. Chapter 6 reconciles them by recovering the points of a smooth curve from its field, as valuations. Chapter 7 then proves the main equivalence of this part of the book: smooth projective curves correspond exactly to function fields of one variable.

**When are two curves the same?** Birational equivalence is a coarse relation and isomorphism a fine one. For smooth projective curves the two coincide (Chapter 7). So to classify smooth projective curves it is enough to classify function fields, and Chapter 17 does that for our cast.

**Which curves can be parametrized?** Exactly the rational ones, those with $k(C)\cong k(t)$. Chapter 9 proves that smooth plane cubics are not rational, and Chapter 16 gives the complete answer.

**Invariants of function fields.** So far we have one: the transcendence degree, which is 1 for every curve. The genus, developed in Chapters 9–12, is the second, and it is the one that matters.

## Variations

These are optional. A hint follows each one.

**Variation 1.** Show that every irreducible plane cubic with a singular point is rational.
*Hint:* By Variation 4 of Chapter 3 there is exactly one singular point. Its multiplicity is 2, because a point of multiplicity 3 would make the equation homogeneous, hence a product of three lines. A line through the singular point therefore meets the cubic in exactly one more point (Proposition 3.4), and the slope of the line is a rational function on the curve. Try it on the folium $x^3+y^3=3xy$.

**Variation 2.** Let $s^2=t^2+1$. Show that $k(t,s)$ is rational by finding $u$ with $k(t,s)=k(u)$. Of which curve is this the function field? Then do the same for $s^2=t^3+t^2$.
*Hint:* $(s-t)(s+t)=1$, so try $u=s-t$. The curve $s^2-t^2=1$ is a hyperbola, and over $\mathbb{C}$ a circle. For $s^2=t^3+t^2$, which is the node, try $u=s/t$.

**Variation 3.** (a) Show that the parametrization $\bigl(\frac{1-t^4}{1+t^4},\frac{2t^2}{1+t^4}\bigr)$ of the circle is two-to-one, and use Lüroth's recipe to find a birational one. (b) What is $[k(t):k(s)]$ for $s=\frac{t^2-1}{t^2+t}$?
*Hint:* (a) This is Chapter 1's parametrization with $t^2$ in place of $t$. The minimal polynomial of $t$ over the image field has $t^2$ as a coefficient. (b) Lemma 5.4 needs lowest terms: cancel the common factor $t+1$ first.

**Variation 4.** The **Mason–Stothers theorem** says the following. Let $k$ have characteristic 0, and let $a,b,c\in k[t]$ be coprime polynomials, not all constant, with $a+b=c$. Then
$$\max(\deg a,\deg b,\deg c)\leq n_0(abc)-1,$$
where $n_0$ is the number of distinct roots. Use it to show that there are no nonconstant rational functions $x(t),y(t)$ with $x^3+y^3=1$, so that the Fermat cubic is not rational.
*Hint:* Write $x=A/C$ and $y=B/C$ with $A,B,C$ pairwise coprime; why can you? Apply the theorem to $A^3+B^3=C^3$. If $N$ is the largest of the three degrees, the theorem gives $3N\leq3N-1$. The same argument works for every exponent $n\geq3$, a function-field shadow of Fermat's Last Theorem. Chapter 9 explains what is really going on, using differentials. The theorem is proved in Lang's *Algebra*.

**Variation 5.** Show that the curve $x^2+y^2=-1$ is not birationally equivalent over $\mathbb{R}$ to the line, although over $\mathbb{C}$ its function field is $\mathbb{C}(t)$. Then decide for which $n$ the curve $x^2+y^2=n$ is rational over $\mathbb{Q}$.
*Hint:* It has no real points. For the second part, combine the argument of Section 5.4 with Chapter 1's line method: the answer is exactly the $n$ for which the curve has a rational point.
